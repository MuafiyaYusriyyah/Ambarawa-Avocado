# Ambarawa Avocado - Siklus Akuntansi (Python desktop + MySQL)

## Menjalankan
1. Nyalakan MySQL (XAMPP: Start pada MySQL).
2. Buka folder ini di VS Code, lalu di terminal: `pip install -r requirements.txt`
3. Cek `config.py` (default: user root, tanpa password, database "alpukat estate").
4. Jalankan **main.py**:  `python main.py`

Tabel dan daftar akun dibuat otomatis saat pertama kali jalan.
Linux: `sudo apt install python3-tk`.

## Cara pakai
Semua input lewat tombol di Beranda (Saldo Awal, Jurnal Umum, Jurnal Penyesuaian, Persediaan).
Daftar Akun punya input sendiri. Halaman siklus lainnya otomatis dari data yang diinput.
